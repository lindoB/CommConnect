# Team Working Agreement — CivicConnect

## 1. Collaboration & Communication
* **Primary Communication Channel:** [e.g., WhatsApp] for daily quick updates.
* **Meetings:** Weekly sync meetings to review PRs, update project boards, and align on upcoming milestone deliverables.
* **Response Time:** Team members aim to respond to urgent project queries within 12–24 hours on weekdays.

## 2. GitHub Governance & Code Quality
* **Protected Branch Policy:** No direct commits to `main`. All work enters via feature branches and Pull Requests.
* **Two-Reviewer Rule:** Every Pull Request requires **two explicit approvals** from the other team members prior to merging. Self-approval is strictly forbidden.
* **Review Turnaround:** Pull Requests must be reviewed within 24 hours of submission to prevent workflow bottlenecks.
* **Traceability:** Every PR must reference a specific GitHub Issue, Requirement ID (FR/NFR), or PED document update.

## 3. Engineering & Document Standards
* **PED Maintenance:** Updates to the Project Engineering Document (PED) must follow strict version control and never silently overwrite historical baseline content.
* **AI Usage:** All AI-generated content (code, architecture, or documentation) must be independently verified and recorded in `docs/AI_USAGE_REGISTER.md`.
* **Individual Accountability:** Each member is responsible for understanding the entire system and being prepared to defend any section of the engineering record during presentations.
