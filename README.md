# CommConnect

CivicConnect - Community Service Request Management Platform

## Project Overview
CivicConnect is an integrated digital platform engineered to streamline, track, and manage community service requests (such as facility faults, maintenance issues, and operational requests). Replacing inefficient informal communication channels like email and WhatsApp, CivicConnect establishes a centralized, traceable system that enhances visibility, accountability, and operational efficiency for requesters, staff, and management.

Developed as part of the **Software Engineering 381 (SEN381)** module at Belgium Campus ITversity.
